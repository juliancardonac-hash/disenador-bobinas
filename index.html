📐 Representación conceptual

La representación es conceptual. Para fabricación real deben considerarse tolerancias, aislamiento, forma exacta del carrete, geometría del núcleo y ficha técnica del material magnético.

📘 Fórmulas utilizadas

Xₗ = 2πfL
L ≈ N² / ℜ
ℜ = le/(μ₀ μr Ae) + lg/(μ₀ Ae)
N = V / (4.44 · f · Ae · Bmax)
Acu = I / J
d = √(4A / π)
R = ρ · l / A
Z = √(R² + Xₗ²)
Pcu = I²R
S = VI
Q = I²Xₗ
FP = R / |Z|

Estas ecuaciones constituyen un modelo preliminar de ingeniería. Un diseño destinado a fabricación debe comprobar pérdidas del núcleo, curva B-H, temperatura, aislamiento, efecto pelicular, efecto de proximidad, dispersión de flujo y tolerancias.
